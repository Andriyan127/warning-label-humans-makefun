The funniest single-line safety warning label that should come printed on every human being — 105 characters, one line, one laugh.

```
WARNING: This unit will insist it is fine while visibly malfunctioning; believe the smoke, not the label.
```

Why it fits the brief: it is written exactly like a real printed WARNING label — hazard, then consequence, then an imperative — until the final clause undercuts the label itself. Every human has said "I'm fine" while visibly falling apart, so the joke lands as recognition, not random absurdity, and the turn arrives in the last few words, in a single read.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (105 characters, no trailing newline).
